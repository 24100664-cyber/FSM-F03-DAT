# FSM-F03-DAT

## 1. Project Overview

**FSM-F03-DAT** is a project developed as part of the course/project requirements at Phenikaa University.

The project focuses on the analysis, specification, design, implementation, and testing of a **Finite State Machine (FSM)** based system.

## 2. Project Structure

```text
FSM-F03-DAT/
├── README.md
├── requirement/
│   └── README.md
│   └── requirements_F03.md
└── specification/
    └── README.md
    └── specification_F03.md
```

### `requirement/`

Contains the project requirements, including functional requirements, non-functional requirements, system constraints, inputs, outputs, and other requirements provided by the project.

### `specification/`

Contains the detailed technical specification developed based on the approved requirements.

## 3. Development Process

The project follows the following development process:

1. Define project requirements.
2. Submit the requirements for review.
3. Receive and update the requirements based on feedback.
4. Develop the system specification.
5. Submit the specification for review.
6. Implement the system according to the approved specification.
7. Test and verify the implementation.
8. Document the final results.

## 4. Repository

This repository is used to manage project documents, specifications, source code, and related development files.
